# Machine Learning Foundations

Hands-on machine learning fundamentals: data ingestion, EDA, feature engineering, preprocessing, and model development. Continuously evolving.

## Overview

This repository is a collection of Jupyter notebooks I write while learning machine learning from the ground up. It is not a finished project or a polished library. It's a working record of what I've studied and implemented, and it grows as I learn more.

## Learning Philosophy

The goal isn't to get code running by calling a library. For each step, from loading data to preprocessing it, I try to understand why it's done, what assumptions it makes, and how it changes the data. Each notebook is an attempt to reason through a workflow, not just reproduce one.
